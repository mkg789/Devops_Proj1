# Devops_Proj1

DevOps workflow
1. GitHub
   
   Clone an existing application.
2. Docker
   
   Write Dockerfiles and build images.
3. Docker Compose
   
   Run frontend, backend and database.
4. Harbor
   
   Push and store Docker images.
5. Kubernetes
   
   Deploy the application.
6. Argo CD
   
   Automate deployment using GitOps.
